Connect your dashboard

A Google web client ID connects this GitHub Pages website to your clinic calendar. You only need to set this up once.

Use a client ID, never a client secret. This ID is saved on this browser; the owner can also set it in the website configuration.

One-time Google setup
  1. Open Google Cloud using the clinic account. Create a project and enable the Google Calendar API.
  2. In Google Auth Platform, set up Branding and Audience. For testing, add inocareklinik@gmail.com as a test user.
  3. Create an OAuth client with application type Web application. Add this authorised JavaScript origin: . Use the origin only, without the repository path.
  4. Copy the client ID into the field above, save, then choose Connect Google Calendar and grant read access.

When Google’s authorisation expires, use Connect again. Automatic updates run while the dashboard is open and connected.
